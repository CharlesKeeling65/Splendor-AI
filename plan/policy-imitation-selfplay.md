# 策略模仿与自博弈实施计划

> 状态：待实施计划。本文不表示新模块、训练、评测或部署已经完成。
> 范围：本地引擎训练与离线评测；不扩大网页权限，不替换旧权重。
> 依据日期：2026-09-07。

## 1. 决策结论

主实验按以下顺序推进：

**教师统一评测与信息审计 → 行为克隆（BC）→ DAgger → PPO 对手池自博弈。**

- corrected DQN 作为持续对照，不因模仿路线启动而替换、覆盖或重新命名旧权重。
- 首个模仿实验只选一个经过验证的教师；多教师要先测冲突和信息一致性，不能盲目混标。
- MCTS 不进入主线首轮；只有在相同权重、明确搜索预算和价值校准均通过门槛后，才进入后续实验。
- PPO、GA、minimax 的既有实现路径保持不改；新训练逻辑若需新文件或入口，必须先核对可复用路径，并在实施记录中标为【拟议模块】。
- 本计划不预先批准下一轮预算、成功阈值或运行时长；启动每次运行前，以独立 manifest 写明并复核。

## 2. 事实依据与解释边界

- [DQN 第二轮结果与选模纠错](../docs/DQN_ROUND2_RESULTS_20260907.md)记载：纠错后的 corrected DQN 对 minimax 为 79/150（52.7%），对 heuristic 为 53/150（35.3%）。
- 同一报告中的引导版 public-demo 对 minimax 为 80/150（53.3%），对 heuristic 为 35/150（23.3%）；它不是只看 minimax 的成功证据。
- 上述分支每个训练 20,000 步，只有三个训练副本；共享牌局与座次使样本并非独立伯努利试验，不能据此判定 DQN 上限或完整课程已收敛。
- 第二轮的浮点同分选模偏差已被报告并纠正；后续选模必须按整数计数和预先声明的规则执行。
- [第一轮结果](../docs/DQN_EXPERIMENT_RESULTS_20260907.md)同样只支持短程、有限副本下的谨慎结论；旧的“GA 最稳”或“PPO 上限高”叙述不等于最新统一评测，当前并没有 GA/PPO 的同口径新结果。
- minimax 是深度 2 的启发式对手，不是最优专家；教师候选的胜率不能被解释为接近最优策略的证明。
- DQfD 说明专家示范可以与 Q 学习结合，因此保留 corrected DQN 对照是必要的；BC 不是唯一合理路线（[DQfD](https://ojs.aaai.org/index.php/AAAI/article/view/11757)）。

## 3. 阶段任务、产物与退出门槛

### 3.0 运行前冻结协议

- [ ] 复核 P5000 现有 venv、GPU 可用性和当前工作区状态；优先复用现有环境，不安装未核准依赖。
- [ ] 先用小模型并行采样验证吞吐、显存、日志完整性和终局处理；不把该冒烟结果当作性能结果。
- [ ] 为每次训练/评测建立 manifest，至少记录代码版本、模型/特征版本、训练与评测种子、座次、牌局分组、预算、硬件、墙钟、GPU、教师查询数和搜索节点数。
- [ ] 在 manifest 中写入本次新范围、资源预算、成功阈值、验证/测试种子和选模规则，并在运行前由人工复核；本计划不替代该批准动作。
- [ ] 明确旧 910000/920000/930000 测试种子不得用于调参或选模；历史结果仅作已封存对照。

**拟议产物**：实验 manifest、逐局记录、成本记录和审计摘要。实际文件位置与复用的现有入口在实施前核验，不预设新命令。

退出门槛：若协议、分母、种子/座次映射、终局记录或信息集定义不能复核，暂停后续训练并保留失败产物。

### 3.1 教师候选统一评测与信息审计

候选角色包括 GA、minimax、旧 PPO、corrected DQN；heuristic 是低成本候选，不能默认指定为唯一教师。它们也可作为固定风格对手，但角色要在 manifest 中分开记录。

- [ ] 让 GA 和旧 PPO 先按与 DQN 可比的同口径重新评测：相同牌局范围、双座次、计数规则、分母和成本记录。
- [ ] 对所有候选报告胜/平/负、calScore、决策耗时、非法动作数、训练/推理成本以及每个训练种子的结果。
- [ ] 检查教师推理只使用学生可获得的公开信息、合法动作掩码和对应观测；禁止用评测时才可见的真实后继信息选动作。
- [ ] 审计模拟后继和动作搜索是否窥见真实牌库顺序、对手隐藏保留牌或其他不在学生信息集内的状态；先记录“待验证风险”，不得写成已证实漏洞。
- [ ] 比较候选的稳定性、信息公平性和行为质量，再按预先声明的规则选首个单教师；不得只凭一项对手胜率挑选。
- [ ] 若考虑多教师，先统计冲突状态、标签覆盖和冲突解决规则；没有预先规则时不混合标签。

**拟议产物**：教师评测表、信息审计清单、候选选择记录和可复现的教师快照引用。

退出门槛：至少有一个信息公平、协议可复核、标签可重放的候选才进入 BC；若多个候选冲突而无法预注册解决规则，先保持单教师或暂停多教师方案。

### 3.2 行为克隆（BC）

BC 的动作头固定覆盖 3510 个枚举动作，采样、损失和评测均先应用合法动作掩码；非法动作不能靠运行时兜底。

- [ ] 采集教师完整轨迹，保存观测、合法掩码、教师动作、牌局/种子/座次和整局边界；不要只保存无上下文的动作列表。
- [ ] 以公开 265 维观测作为首个基准候选，并以公开 312 维观测做小规模单因素对照；一次只改变观测维度，不同时改变教师、数据量、网络和训练预算。
- [ ] 记录训练集、验证集、最终测试集的整局与种子归属，确保同一整局或同一牌局簇不会跨集合泄漏。
- [ ] 评估掩码后的合法率、动作一致率、固定对手池对局表现、calScore 和决策耗时；动作一致率只作诊断，不作唯一成功标准。
- [ ] 保留 corrected DQN 作为同协议对照，并保存 BC 训练配置、数据摘要和未覆盖状态统计。

**拟议模块/产物**：教师轨迹采集器、BC 数据集读取与掩码训练适配层、BC checkpoint 和数据 manifest；实际 API、路径和入口待实施时先查现有代码再定。

退出门槛：数据切分、掩码、标签重放和成本统计全部可审计；性能门槛使用运行前 manifest 中的批准值，不能事后根据测试集另定。

### 3.3 DAgger

DAgger 的学生（或早期师生混合策略）访问状态后查询教师标签，聚合历史数据；它不要求实际执行教师动作才能收集该标签。

- [ ] 设计逐轮数据聚合：保留历史数据版本、访问策略、教师查询记录和对应整局/种子。
- [ ] 允许学生在状态访问中执行自己的动作；查询到的教师动作作为标签写入聚合集，不把“自己采样动作”误称为强化学习标签。
- [ ] 评测阶段移除教师查询和教师动作执行，单独运行学生策略。
- [ ] 以整局和种子切分聚合数据，防止同牌局状态同时出现在训练和最终测试中。
- [ ] 对照 corrected DQN、BC 与 BC+DAgger；必要时增加早期师生混合的单独消融，保持一次只解释一个主要变化。
- [ ] 用固定对手池的对局表现、calScore、决策耗时和教师查询成本验收；不以动作一致率或“对教师达到 50%”作为充分条件。

DAgger 的目标是在学生自身访问的状态分布上稳健模仿教师，不保证超越教师；若对局收益没有改善但成本显著增加，应停止扩大聚合轮次。

**拟议模块/产物**：状态访问与教师查询适配层、历史数据聚合器、DAgger 版本清单；不得假定这些模块已经存在。

退出门槛：无教师评测可独立复现，数据泄漏和查询成本可计数，且与 BC 的差异可归因；否则不进入 PPO。

### 3.4 PPO 对手池自博弈

PPO 沿用已预训练的 policy，并新增或训练 critic；旧 PPO 只有 Δscore 目标，不能直接照搬为本路线的终局价值目标。

- [ ] 明确终局处理，使用 calScore 及预先声明的胜负/平局价值映射；检查终局 bootstrap、截断和非终局奖励一致。
- [ ] 组成对手池：选定教师、通过审计的固定基线、当前策略冻结副本及历史快照；GA、minimax、旧 PPO、corrected DQN 等候选的纳入和采样权重以同口径复测为依据。
- [ ] 每局开始时固定一个对手，整局不在多个对手之间切换；记录对手身份、快照和座次。
- [ ] 保留 corrected DQN、BC、BC+DAgger、DAgger+PPO 四个主要比较点；同一评测协议下保存所有消融结果。
- [ ] 可保留小权重模仿正则以减轻遗忘，但只依据验证集调整并记录；不机械沿用 16,000 步退出规则。
- [ ] 分清强化学习与伪标签：学生与环境交互所得动作不是教师标签，PPO 必须由环境回报和终局处理驱动。
- [ ] 以固定对手池表现、成本、稳定性和跨种子结果决定是否扩大自博弈，不以单个对手或单个幸运 checkpoint 决定。

**拟议模块/产物**：policy 预训练加载与 critic 训练适配、固定对手池配置、PPO 运行 manifest；命名和接口待实现前核验。

退出门槛：critic 的目标和终局语义经手算/小样本检查，旧 PPO 路径不被改写，当前冻结副本可重放；若遗忘或对手池混淆无法诊断，暂停扩大训练。

### 3.5 MCTS 门槛实验（后续）

- [ ] 先用同一权重比较无搜索与多个搜索预算，记录胜率、calScore、决策墙钟和搜索节点数。
- [ ] 校准价值头，确认其输出语义；不能把 DQN 的 score-return Q 直接当作胜率价值。
- [ ] 审查隐藏信息重采样、随机性、牌库顺序和模拟后继语义，确认搜索没有使用学生不可见信息。
- [ ] 只有在收益、价值校准和语义审计均通过后，才设计搜索访问分布蒸馏与自博弈。

旧实验中 16 次模拟约有 49 倍决策延迟且未见收益；这只能作为预算警示，不能泛化为“ MCTS 无效”。本路线不是直接照搬完全信息 AlphaZero（参考 [OpenSpiel AlphaZero 文档](https://github.com/google-deepmind/open_spiel/blob/master/docs/alpha_zero.md)）。

## 4. 统一对照与评估协议

- [ ] 所有主要比较均使用多训练 seed、双座次、相同规则和明确的牌局分组；每局只固定一个对手。
- [ ] 将 corrected DQN、BC、BC+DAgger、DAgger+PPO 作为主消融；MCTS 只在门槛实验中出现。
- [ ] 分别设置验证集与最终测试集；模型选择只看验证集，最终测试完成后不得回调参数或重选模型。
- [ ] 选模按整数胜/平/负计数和预先声明的精确同分规则执行，避免浮点平均造成伪提升。
- [ ] 显式报告每个分支、seed、对手、座次和总分母；平局如何计入胜率必须固定并写入 manifest。
- [ ] 置信区间按牌局/牌局簇处理同牌双座次关联，不能把共享牌局拆成独立伯努利样本。
- [ ] 同时报告交互步数、教师查询数、搜索节点数、墙钟、GPU 时间/成本和决策延迟；不要只比较最终胜率。
- [ ] 训练、验证和最终测试记录失败局，不为抬高分母静默排除；历史快照仅作对照，不与新预算混作因果结论。
- [ ] 评测无教师、无搜索泄漏；教师查询和搜索开销单独列出。

## 5. 风险与执行顺序

主要风险是教师并非最优、教师信息泄漏、教师间冲突、特征与训练预算混杂、DAgger 数据泄漏、PPO 终局价值错配、对手池非平稳和成本不可比。每一项先记录为待验证风险，只有审计证据支持后才升级为结论。

建议顺序：

1. [ ] 冻结协议、核查范围/预算并写 manifest。
2. [ ] 统一复测教师候选并完成信息审计。
3. [ ] 选单教师，做小规模 BC 265/312 观测对照。
4. [ ] 通过 BC 数据与评测门槛后再做 DAgger。
5. [ ] 通过无教师 DAgger 验收后再做固定对手池 PPO。
6. [ ] 独立满足 MCTS 门槛后才做搜索蒸馏与自博弈。

旧权重保持可读且不替换；PPO/GA/minimax 存量路径保持不改；本计划不启动真实网页对局，也不改变 sim-to-real 权限。

## 6. 首次实施范围

下一次运行只建议先覆盖以下可核验范围：

- [ ] 复核 P5000 现有 venv，做小模型并行采样吞吐验证。
- [ ] 建立本次 manifest，确认新种子、双座次、验证/测试隔离、分母、成本字段和批准预算/阈值。
- [ ] 对 GA、minimax、旧 PPO、corrected DQN 和 heuristic 候选做同口径教师评测与信息审计。
- [ ] 选择一个单教师并保存可复核引用；若无候选通过，不进入模仿训练。
- [ ] 在不同时改变其他因素的前提下，开展 265/312 公开观测的最小 BC 对照，并保留 corrected DQN。

DAgger、PPO 对手池自博弈和 MCTS 不属于首次范围，须分别通过前一阶段退出门槛后再开新 manifest。首次运行不承诺工期、效果或部署结果。
