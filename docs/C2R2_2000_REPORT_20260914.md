## 成功经验

1. **规模 × 塑形的复合收益是真的**：两项改动叠加后所有学习型可打的对手
   全线上移（minimax +10、GA +16、heuristic +9pt），且验证最优从 34–37 升至
   44–48/60。EV@u1000 达 0.40–0.43（历史最高），说明 critic 在长训下仍在
   吸收信号。
2. **potential shaping 的贡献路径是"改策略"而非"改 critic 拟合"**：塑形后的
   return 目标含势能项，value_loss 稳定在 ~7 且 EV 并未随规模单调上升
   （u1000 达峰后回落，clip fraction ~0.001 更新保守）——**自博弈的非平稳
   目标下 EV 不是实力的单调代理，胜率门槛才是**。G2 的"EV ≥ 0.5"表述需要
   修订为"EV 不发散 + 胜率门槛"（§11 回填）。
3. **telescoping 语义经得起长训**：2000 updates × 3 seed 全程零失败局、
   零发散（returns 有限、KL 早停正常），B2 的势能锚定/记账实现在 ~96k 局
   上无一处数值问题。
4. **选模协议有效**：验证整数胜局（48/60）选出的 seed1234 在终测 minimax
   54%——验证与终测方向一致（虽个别 seed 终测更强，如 2024 的 68%，但
   选模只能用验证段，纪律未破）。

## 失败/不足与原因

1. **heuristic 族仍是唯一缺口（46% vs 60%）**：rush/hoard 变体与冻结
   heuristic 的"即时买分"风格依旧克制我们的策略。上轮归因（池权重、塑形
   路径）部分见效（+9pt）但不够。下一轮药方：池权重向 heuristic 族倾斜
   （如 heuristic:2,rush:2,ga:1,minimax:1）+ rush 教师 DAgger 蒸馏（待
   corrected 教师）。
2. **EV@u2000 回落（0.44→0.29–0.44）**：自博弈目标非平稳的固有现象；
   若追求 G2 的 EV 字面门槛，需要冻结对手快照的校准批而非自博弈流。
   记录为度量定义问题而非训练失败。
3. **归因未做单因素拆分**：C2-R2 同时引入规模（4×）与塑形，未单独消融
   塑形贡献。成本上单因素需再跑 2×6h；鉴于两者方向在 C2/B2 冒烟各自
   有据，复合结果先入档，塑形单因素消融列为可选后续。

## 复现

```bash
PYTHONHASHSEED=0 python -m splendor.agents.our_agents.policy_imitation.stabilization \
  --output runs/c2r2-selfplay-2000 --device cuda --workers 3 \
  --updates 2000 --games-per-update 16 --eval-every 50 \
  --variants fixed --seeds 42 1234 2024 \
  --value-coefficient 1.0 --critic-learning-rate 5e-4 \
  --shaping potential --shaping-kappa 0.05 \
  --pool-names ga,heuristic,heuristic-rush,heuristic-hoard,minimax \
  --seed-base 940000 --training-seed-count 96000 \
  --initial-bc runs/policy-imitation/formal-3.3-20260907/bc-dagger-2/best.pth
```
