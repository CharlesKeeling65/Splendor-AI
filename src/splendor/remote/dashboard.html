胜率怎么算？

在当前可见局面重建的完整引擎状态上，用当前策略自对弈模拟 N 局至终局 （未知牌库 / 对手预留按注册表均匀抽样补全），某座位以最高分终局的频率 （同分按卡数少者 tie-break，仍并列各计 0.5）。图表只显示最近一局，x 轴每局从 0 重新计数。 同一序号画两个点：空心圆 = 操作前，实心方 = 操作后；竖细线表示该步估计失败或降级（stale）。
